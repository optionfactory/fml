ful kitchen sink

Every control on this page is styled by dist/ful.css alone: no bootstrap css, no bootstrap js, no icon font. Invalid fields are forced through the public setCustomValidity, exactly like a server answer would. The focused field is a presentational replica painted with the library's own custom properties: nothing is focused there, tab through the page for the real rings.
